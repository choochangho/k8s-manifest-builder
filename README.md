# K8s Manifest Builder

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**배포된 페이지**: https://k8s-manifest-builder.vercel.app

쿠버네티스 매니페스트(YAML)를 작성할 때 공식 API 문서를 오가지 않아도 되도록 도와주는 단일 페이지 도구입니다.

오브젝트를 선택하면 속성이 트리 구조로 나타나고, 각 필드마다 **필수/권장/선택** 여부와 의미 설명을 바로 보여주며, 값을 입력하는 즉시 오른쪽에 완성된 YAML이 실시간으로 만들어집니다.

- 설치 없이 `index.html`을 브라우저에서 열면 바로 동작합니다 (외부 의존성·백엔드·빌드 과정 없음).
- Pod, Deployment, Service, Ingress, RBAC, StatefulSet 등 **26종**의 주요 쿠버네티스 오브젝트를 지원합니다.
- 실제 쿠버네티스 스키마와 동일한 계층 구조로 YAML을 생성합니다.

## 시작하기

별도 설치가 필요 없습니다. 아래 중 편한 방법으로 `index.html`을 브라우저에서 열면 됩니다.

```bash
# 방법 1: 파일을 바로 열기 (macOS)
open index.html

# 방법 2: 로컬 서버로 띄우기
python3 -m http.server 8934
# 이후 브라우저에서 http://localhost:8934/index.html 접속
```

## 사용 방법

1. **오브젝트 선택** — 왼쪽 사이드바에서 만들고 싶은 쿠버네티스 오브젝트(Pod, Deployment, Service 등)를 클릭합니다. 목록은 "사용 빈도순" 또는 "이름순"으로 정렬할 수 있습니다.
2. **네임스페이스 지정(선택)** — 상단바에 네임스페이스를 입력하면, 개별 오브젝트에서 네임스페이스를 비워둔 경우 자동으로 채워집니다. (Namespace, ClusterRole 등 클러스터 범위 오브젝트에는 적용되지 않습니다.)
3. **필드 채우기** — 가운데 속성 트리에서 각 필드를 확인합니다.
   - 배지 색으로 필수(빨강)/권장(노랑)/선택(회색) 여부를 구분합니다.
   - 필수 필드는 항상 포함되며 체크 해제할 수 없습니다.
   - 선택 필드는 체크박스를 켜면 입력 칸이 나타납니다.
   - object·list 타입 필드는 좌측 `+`/`−` 아이콘으로 펼치거나 접을 수 있고, 상단의 "모두 펼치기/모두 접기" 버튼으로 한 번에 전환할 수 있습니다.
   - map, 문자열 목록, 반복 가능한 항목(예: 컨테이너, 포트, 규칙)은 "+ 항목 추가" 버튼으로 늘리고, 각 항목의 "삭제" 버튼으로 줄일 수 있습니다.
4. **YAML 확인 및 복사** — 오른쪽 패널에 입력한 값이 즉시 반영된 YAML이 나타납니다. 우측 상단의 **복사** 버튼을 누르면 전체 YAML이 클립보드에 복사됩니다.
5. **다른 오브젝트로 전환** — 사이드바에서 다른 오브젝트를 클릭하면 트리가 새로 초기화됩니다(입력값은 유지되지 않습니다).

## 지원 범위 밖

- 클러스터에 직접 배포하는 기능(`kubectl apply` 등) — 읽기 전용 생성 도구입니다.
- 여러 오브젝트를 하나의 멀티 도큐먼트 YAML로 묶어 내보내기
- 기존 YAML을 불러와 트리에 역으로 채우는 기능(가져오기)
- 서버 저장·공유·로그인·협업 기능

## 개발 노트

이 프로젝트는 다음과 같은 과정으로 만들어졌습니다.

- **기획**: [`docs/PRD.md`](docs/PRD.md)는 Claude 웹(claude.ai)에서 먼저 작성했습니다.
- **구현**: Claude Code로 PRD를 기반으로 전체 기능을 구현했습니다.
- **디자인 참고**: 다크 테마 색상 팔레트는 [getdesign.md](https://getdesign.md)에서 여러 개발자 도구의 디자인 시스템 분석을 비교한 뒤, Gitness의 방향(완전 블랙 배경 + 뉴트럴 그레이 + 화이트 CTA 포인트)을 참고해 정했습니다.
- **검증**: 별도의 테스트 스위트 없이, 변경할 때마다 아래 도구로 직접 확인하며 진행했습니다.
  - `node --check`로 JavaScript 문법 오류를 우선 확인
  - Python 내장 모듈(`python3 -m http.server`)로 로컬 서버를 띄운 뒤
  - Chrome 브라우저 자동화(Claude in Chrome)로 실제 화면에서 동작(트리 조작, YAML 실시간 생성, 복사 등)을 직접 클릭·입력해 확인
